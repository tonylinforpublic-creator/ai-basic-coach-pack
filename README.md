> 你可以複製、下載、照著做你自己的網頁；只是不能轉載或拿去教別人（說明在最下面）。

## 現在就做這三件事（用電腦最順，大約五分鐘）

1. 打開 **ChatGPT**（chatgpt.com），**先登入**（明天才找得回今天的對話），開一個**新的對話**
2. 把 `00-給AI的總指令.md` 交給它：
   - 在這一頁**往上滑**，最上面有一排檔案名稱，點 `00-給AI的總指令.md`
   - 打開後，按右上角「複製」的小圖示（兩個方框疊在一起）
   - 回到 ChatGPT，在對話框按右鍵「貼上」
3. 貼上後會出現**一大段字，這是正常的**，直接按送出。它會開始問你「今天想做哪一種網頁？」，回答題目就好

> 上課做到一半？直接跟它說「我做到第 ○ 步了」（①一句話 ②說多一點 ③發散 ④收斂 ⑤統整 ⑥生成 ⑦修正）。
> 用手機的話，複製比較難找，請家人幫忙，或改用電腦。
> 家裡有人會用電腦的備案：按綠色 **Code → Download ZIP**，解壓縮後把 `00-給AI的總指令.md` 拖進 ChatGPT 對話框。

## 記得三件事

1. **密碼、身分證、存摺，不要打給 AI**
2. **叫你付錢、匯款的，先問家人**——今天用的全部免費
3. **AI 也會說錯**，網頁上的電話、地址自己再看一次
