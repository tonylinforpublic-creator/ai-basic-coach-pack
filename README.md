## 現在就做這三件事（兩分鐘）

1. 打開 **ChatGPT**（chatgpt.com），開一個**新的對話**
2. 把 `00-給AI的總指令.md` 交給它，兩種方法選一種：
   - **在這個網頁上**：點下面檔案列表裡的 `00-給AI的總指令.md` → 按右上角「複製」的小圖示（兩個方框疊在一起）→ 回 ChatGPT 貼上
   - **下載到電腦**：按綠色 **Code → Download ZIP**，解壓縮後把 `00-給AI的總指令.md` 拖進 ChatGPT 對話框
3. 打兩個字：**開始**

它會問你「**做到第幾步了？**」——看今天的步驟條回答就好（①一句話 ②說多一點 ③發散 ④收斂 ⑤統整 ⑥生成 ⑦修正）。
